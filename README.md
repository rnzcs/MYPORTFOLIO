# Renz's Portfolio

Hi, I'm Renz, a full-stack developer from Olongapo City, Philippines. This repository contains the code for my portfolio site. The Projects section features SafePath, a campus navigation project for Gordon College.

## Live sites

- Vercel: https://portfolio-one-xi-glrl91glot.vercel.app
- Firebase Hosting: https://renzportfolio.web.app

## Run locally

Open `index.html` in a browser, or use VS Code Live Server. There is no build step.

The contact form opens a prefilled email in your default mail app. You still need to send it from there.

## Project files

- `index.html` - page content
- `style.css` - layout and responsive styles
- `script.js` - navigation, project details, and contact form
- `safepathnewlogo.jpg` - SafePath logo used in the featured project

## Deploy

This site is set up for Vercel and Firebase Hosting. Sign in to the relevant CLI, then run:

```sh
vercel --prod
firebase deploy --only hosting
```
